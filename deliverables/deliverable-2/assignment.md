## What the documentation PDF must contain

1. (If there were any updates) Updated requirements clarification questions and answers.
2. **Use-case diagram**, clearly illustrating the system boundary and actors (including system actors).
3. **All use cases in fully-dressed form** — only **3 use cases per team member**.
4. **Domain model.**
5. **System Sequence Diagrams (SSDs) with Operation Contracts** — only for the 3 use cases per member.
6. **UI initial drafts** — wireframes or any other tool; hand-drawn is acceptable, but the figure must be clear in both the submission and the presentation.

Use the **given document template**.
